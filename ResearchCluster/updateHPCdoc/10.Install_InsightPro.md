# InsightPro Server Installation

## 1. Extract the Installation Package

```bash
unzip AltairInsightPro_771_ea0bece4.zip
cd dist/
```

---

## 2. Verify Version Information

```bash
cat VERSION
```

---

## 3. Check Prerequisites

This script automatically installs **K3s** and **Helm** if they are not already installed.

```bash
sudo ./prerequisite_check.sh
```

---

## 4. Identify the Server IP Address

Check all available IP addresses on the server.

```bash
hostname -I
```

> **Note**
>
> Select the correct server IP.
>
> Avoid using internal Docker/Kubernetes interfaces such as:
>
> * docker0
> * cni0
> * flannel.*

---

## 5. Install InsightPro Server

### Parameters

| Variable                       | Description                                                                   |
| ------------------------------ | ----------------------------------------------------------------------------- |
| `INSIGHTPRO_INSTALLATION_PATH` | Installation directory (default: `/opt/altair`)                               |
| `LMX_LICENSE_PATH`             | License server in the format `<port>@<license_server_host>`                   |
| `SERVER_PUBLIC_IP`             | Public IP used for portal access, SSH authentication, and agent communication |

> **Important**
>
> `LMX_LICENSE_PATH` only supports a **single** license server.
>
> Do **not** use HAL multi-server syntax.

Run the installation:

```bash
sudo INSIGHTPRO_INSTALLATION_PATH=/opt/altair/ \
LMX_LICENSE_PATH=6200@172.18.0.2 \
SERVER_PUBLIC_IP=192.168.33.4 \
./AltairInsightPro_install_server.sh
```

---

## 6. Start the Service

```bash
sudo systemctl start insightpro
```

---

## 7. Verify Installation

Check the service status:

```bash
sudo systemctl status insightpro
```

Verify the following messages appear in the log:

* Authentication host is reachable...
* License server is reachable.
* Agent-Server Communication host is reachable.

The portal should be accessible at:

```text
https://192.168.33.4:32443/insightpro
```

# InsightPro Agent Reinstallation

Use this procedure when reinstalling the agent or after deleting/recreating the cluster.

## 1. Uninstall the Existing Agent

```bash
source /etc/insightpro_agent.conf

sudo $AGENT_INSTALLATION_DIR/exec/scripts/insightpro_agent/uninstall.sh
```

---

## 2. Remove the Stale Redis Password File

This resolves the **WRONGPASS authentication** error.

```bash
rm /HA/pbs/pbs_home/server_priv/streamer.pass
```

---

## 3. Reinstall the Agent

Obtain the latest installer command from the InsightPro portal if the cluster has been recreated.

```bash
curl --tlsv1.3 -s -k https://192.168.33.4:32443/insightpro_agent/artifacts/agent_installer_script.sh | \
sudo -E INSIGHTPRO_AGENT_INSTALLATION_PATH=/opt/altair bash
```

When prompted:

```text
Enable all the settings for live monitoring? (y/n)
```

Answer:

```text
y
```

---

## 4. Start the Agent Service

```bash
sudo systemctl start insightpro_agent
```
