# Change config
- SSH to the switch
```bash
ssh admin@192.168.32.111
```

- Change FS config to rs-fec
```bash
# Enable
SUTD-hpc-sw2 [standalone: master] > enable

# Config terminal
SUTD-hpc-sw2 [standalone: master] # config terminal

# Choose port
SUTD-hpc-sw2 [standalone: master] (config) # interface ethernet 1/31

# Overwrite fec
fec rs-fec force
```
