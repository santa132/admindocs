# Change config
- Connect to the switch
```bash
sudo screen /dev/ttyUSB0 115200
```

- Change FS config to rs-fec
```bash
# Enable
 > enable

# Config terminal
 # config terminal

# Choose port
(config) # interface eth-0-1

# Overwrite fec
fec rs

(config) # end
```

- Check port config
```bash
# show interface eth-0-1

```
